# Dataclasses in Python

A progressive series on `@dataclass`: each step is a standalone, runnable
file that carries forward everything from the previous step and adds one
new concept.

## Steps

1. basic fields
2. default values
3. `__post_init__`
4. `field()` options
5. frozen (immutable + hashable)
6. ordering
7. inheritance
8. nested dataclasses
9. conversion (`asdict`/`astuple`/`replace`)
10. slots
