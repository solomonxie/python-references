# Object-Oriented Design (OOD interview problems)

Classic "design a system" interview questions, each solved as a small,
runnable class model:

- `01_parking_lot.py` — floors/spots, assign smallest fitting spot to a vehicle
- `02_elevator_system.py` — dispatch requests to the nearest idle-ish elevator
- `03_library_management.py` — books, members, checkout/return with a loan cap
- `04_tic_tac_toe.py` — n x n board with row/column/diagonal win detection
- `05_vending_machine.py` — state machine driving inventory and change
- `06_rate_limiter.py` — sliding-window-log per-client rate limiting
