# pandas

Basics of the pandas data-analysis library, one focused script each:

- `01_series_dataframe.py` — Series and DataFrame construction
- `02_indexing_filtering.py` — loc/iloc selection and boolean filtering
- `03_groupby_aggregation.py` — split-apply-combine with groupby
- `04_missing_data.py` — detecting, dropping, and filling NaN values
- `05_merge_join.py` — merge (joins) and concat
