# NumPy

Basics of the NumPy array library, one focused script each:

- `01_array_creation.py` — building arrays from lists, ranges, and constructors
- `02_indexing_slicing.py` — slicing, boolean masks, fancy indexing
- `03_broadcasting.py` — applying ops across mismatched shapes
- `04_aggregations.py` — sum/mean/min/max and axis-wise reductions
- `05_linear_algebra.py` — dot products, matrix multiply, inverse, eigenvalues
